# 🎡 StickerHub — игры со стикерами

> ⚠️ **18+** — в названиях стикеров есть мат и чёрный юмор. Вы предупреждены.

Браузерный хаб из трёх мини-игр, в которых вы выигрываете коллекционные **стикеры с абсурдными матерными и черношуточными названиями**. Всё в киберпанк-стилистике: неон, VHS-сканлайны, глитч, грязь и кровь по краям экрана.

## 🎮 Игры

| Игра | Файл | Суть |
|------|------|------|
| 🎡 Колесо фортуны | `index.html` | Крутите неоновое колесо — стикеры, ×2, редкий+, джекпот ×3 или «пусто» |
| 🎰 Слот-машина | `slots.html` | Три барабана: тройка — джекпот, пара — тоже даёт стикер |
| 🔢 Лотерея 6 из 49 | `lottery.html` | Выбираете 6 чисел, лототрон тянет шары, совпадения приносят стикеры |

## ✨ Фичи

- **1006 уникальных стикеров** — на каждый эмодзи своё сгенерированное название: мат, чернуха, исторические личности и события с тёмным юмором
- **5 тиров редкости**: обычный → необычный → редкий → эпический → легендарный
- **Отдельная коллекция для каждой игры** — соберите все 1006 в каждой
- **Прогресс сохраняется** в `localStorage` (отдельно по играм)
- **Звук**: фоновая музыка + сигнал при выпадении легендарки, с кнопкой mute
- **Киберпанк-UI**: HUD-панели с неоновыми уголками, скошенные кнопки, глитч-заголовок «SYSTEM ONLINE», вращающееся пунктирное кольцо вокруг колеса
- **VHS-эффекты** точечно: шапка, шары лототрона, квадраты барабанов, выбранные числа
- **Грязь, потёртости и кровь** на фоновом слое по краям экрана
- Чистый ванильный **HTML/CSS/JS — без сборки и зависимостей**

## 🚀 Запуск

Никакой сборки не нужно:

```bash
# просто открыть файл
open index.html            # macOS
start index.html           # Windows

# или поднять локальный сервер (рекомендуется)
python3 -m http.server 8000
# → http://localhost:8000
```

## 📁 Структура

```
├── index.html        # колесо фортуны
├── slots.html        # слот-машина
├── lottery.html      # лотерея 6/49

├── bg-*.png          # фоны страниц
├── grime.png         # текстура грязи/потёртостей
├── blood.png         # текстура крови
├── stickers/         # картинки для конфетти/наград
└── audio/            # фоновая музыка и звук легендарки
```

## 🌐 Деплой на GitHub Pages

Репозиторий полностью статический, поэтому:

1. Запушьте его на GitHub
2. В репозитории: **Settings → Pages → Source: Deploy from a branch**
3. Ветка `master` (или `main`), папка `/ (root)` → **Save**
4. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`
